# Figma 设计转代码

把 Figma 节点实现为符合当前项目技术栈和设计系统的生产代码。

1. 确认当前工具列表中存在名称以 `get_design_context` 结尾的 Figma MCP 工具，并读取用户指定链接或 Figma Desktop 当前选区的设计上下文；需要视觉基准时调用同一服务中名称以 `get_screenshot` 结尾的工具。
2. 检查当前代码库的框架、路由、组件、样式约定和设计令牌。优先复用现有组件与资源，不引入平行设计系统。
3. 将 Figma 结构转换为符合项目习惯的布局。保留关键尺寸、间距、排版、颜色、状态和响应式行为，但不要机械复制无意义的绝对定位。
4. 只实现用户指定范围。缺少交互状态或响应式规则时，依据现有产品模式做最小合理推断并明确说明。
5. 完成后运行与改动风险相称的类型检查、测试或本地预览；可进行视觉核对时，对照 Figma 截图修正明显偏差。

若 Figma MCP 未连接、节点无法读取或返回内容不完整，应说明具体阻塞并停止臆造设计细节。
