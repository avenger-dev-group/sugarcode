# Figma Code Connect

将 Figma 组件与代码库中真实存在的组件建立可维护的映射。

- 先通过 Figma MCP 获取目标组件及现有 Code Connect 映射，再检查代码库中的候选组件、属性类型、导出路径和用法。
- 只有在 Figma 变体与代码属性语义明确对应时才创建映射；名称相似不足以证明它们是同一组件。
- 遵循仓库已经采用的 Code Connect 文件格式、目录和框架约定。没有现有约定时，根据当前技术栈选择官方支持的最小配置。
- 生成的示例应使用真实导出、有效属性和值，并尽量复用项目已有示例。
- 写入或更新映射后，使用可用的校验方式检查语法和引用；如果 MCP 提供添加映射工具，仅在用户要求提交映射时调用。
- 权限不足、组件未发布或映射目标不明确时，报告缺失信息，不创建猜测性映射。
