# Figma 选区上下文

在分析或实现前，从已连接的 Figma MCP 获取真实设计数据。

- 先确认当前工具列表中存在名称以 `get_design_context` 结尾的 Figma MCP 工具；若没有，说明 Figma Desktop MCP 未能为本次任务激活，不要猜测工具名、设计结构或建议安装 Figma CLI。
- 用户提供 Figma 节点链接时，从链接使用对应节点；用户要求读取当前选区时，使用 Figma Desktop 当前选择。
- 优先读取设计上下文；需要核对视觉效果时再获取截图，需要了解大范围层级时再读取元数据。
- 总结尺寸、自动布局、间距、颜色、排版、圆角、组件和变量。区分 Figma 明确提供的值与根据上下文得出的推断。
- 保持读取范围聚焦。选区过大或结果截断时，请用户缩小到具体 Frame 或组件后重试。
- 除非用户要求实现或修改文件，否则只返回设计分析，不改动代码。
