# 本地定时任务与产物审阅

左侧「定时任务」进入管理面板。创建时填写任务名称、执行指令、工作目录、时间和模型；支持单次、每天、工作日和每周。工作目录留空时，在系统文档目录的 `SugarCode/Automations` 下建立独立目录。

也可以在普通对话输入明确指令，例如「帮我创建一个定时任务，每天早上 9 点分析昨天的销售数据并生成 Excel」或「创建一个定时任务，5 分钟后提醒我检查报表」。频率、时间和执行内容完整时直接创建并打开定时任务面板；信息不完整时打开预填表单，明确列出待补字段，补齐后再保存。普通讨论中仅提到“定时任务”不会被误识别为创建指令。

应用必须持续运行，电脑必须开机且不休眠。任务按电脑本地时区运行；不提供关机执行或系统唤醒。建议先「立即运行」一次，确认模型、资料、连接器和项目环境均可用。需要无人值守调用工具时，可以在计划中勾选「自动批准此任务的工具操作」；首次项目环境信任仍沿用现有审批流程。

每次执行创建独立的隐藏对话，不加入普通项目或工作台会话列表；任务复用现有 Agent、技能和工具系统。结果进入「执行记录」，可用「待审阅」筛选集中处理。打开结果后，中间区域在定时任务模块内展示本次执行的指令、处理过程和回复，并支持继续追问；产物在右侧打开。也可停止运行或标记审阅。暂停或删除计划不会删除历史记录和文件。修改计划只影响之后的执行。

同一计划不会重叠运行，最多同时执行 3 个定时任务。调度每 15 秒检查一次，延迟超过 90 秒的时间点记为「已跳过」，恢复运行后可手动补跑；并发已满也记录为跳过。单次执行默认最长 120 分钟，可修改为 1–1440 分钟。应用重启后，之前尚未结束的运行标为中断，不自动重复执行。

## 右侧文件工作区

| 格式 | 内置能力 |
| --- | --- |
| UTF-8 文本、Markdown、代码、CSV | 查看文本，直接修改与保存 |
| `.xlsx` | 工作表切换、拖动框选、行列选择、公式编辑与即时重算、常用函数、批量复制粘贴、清空及横向/纵向填充；显示前 500 行、50 列，其余内容保留 |
| `.docx` | 文档版式预览，修改正文和表格中的段落文字 |
| `.pdf` | 翻页、缩放，保存独立审阅批注 |
| 常见图片 | 图片预览 |
| 其他格式（包括旧版 `.doc`、`.xls`） | 使用系统应用打开、定位、导出 |

Word 编辑保留文档包中的样式、图片和表格，不提供完整 Office 排版编辑。Excel 内置计算支持四则运算、引用与区域，以及 SUM、AVERAGE、MIN、MAX、COUNT、COUNTA、SUMPRODUCT、IF、IFERROR、COUNTIF、SUMIF、AVERAGEIF、VLOOKUP、XLOOKUP、ROUND、文本和逻辑等常用函数；依赖单元格变化后按需重算并缓存本次预览结果，单个公式区域最多计算 5 万个单元格。保存时仍设置 Excel 打开后完整重算，因此未内置的高级函数会由 Excel 处理。合并单元格仅主单元格可编辑。PDF 批注单独保存，不改写 PDF 原文，导出 PDF 原文件不会携带这些批注。单文件内置读取上限 25 MB，文本上限 2 MB；超限可用系统应用打开。

修改在本地暂存；保存前校验文件版本，发现外部修改时拒绝覆盖。保存文本、Word 和 Excel 前保留旧版本。文件工作区与定时任务独立，也可用于日常对话产生的文件。

## 存储与实现

- 计划和执行记录：应用用户数据目录的 `schedules-v1.json`，原子替换保存。
- 每次运行的产物目录：工作目录下 `.sugarcode/automations/<scheduleId>/<runId>/`。Agent 收到保存位置指令，完成后自动扫描该目录；最终回复也保留任务摘要。
- 编辑前版本：`.sugarcode/versions/<pathHash>/`。
- PDF 批注：`.sugarcode/reviews/<fileIdentity>.json`。
- 调度服务：`apps/desktop/src/main/schedules/`；文件处理：`apps/desktop/src/main/artifacts/`。
- IPC 复用可信窗口校验；文件访问校验当前工作目录和实际路径；调度记录损坏时保留原文件并暂停调度。

## 验证

`pnpm typecheck`、`pnpm lint`、`pnpm --filter @sugarcode/desktop test:node`。

`pnpm test:e2e` 使用独立应用数据目录，覆盖创建计划、后台失败记录、结果导航，以及右侧四类文件的渲染与保存。测试故意指定不存在的模型，不访问真实模型服务。调度成功完成、结果归集、防重、并发和恢复由运行时模拟测试验证。
